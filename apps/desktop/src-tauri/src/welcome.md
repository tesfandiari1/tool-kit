# Welcome

This is a real file. It sits at `Inbox/welcome.md` inside your workspace folder. Edit it, or delete it and it stays deleted.

## Two columns

The left column is your library: every project folder and the files inside it. Click a markdown file and it opens on the right. Click anything else and a card tells you what it is.

**Run** and **History** share that left column. Run converts and transcribes. History lists every finished job and where the result went. Press ⌘, for Settings.

## Turning a file into text

Drop a PDF, a Word file, an image, or an audio file anywhere on this window, then press Run. The result lands beside the source, so `deck.pdf` becomes `deck.md` in the same folder and the tree shows the two on one row.

A file with no result yet carries a **Convert** button. Press it to convert that one file.

## Where things live

Your workspace is a plain folder. Projects are folders inside it. Documents are plain `.md` files. Finder and Time Machine see everything the app sees, so nothing here is locked away in a database.
