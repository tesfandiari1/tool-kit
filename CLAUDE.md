# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**Read [`docs/STATUS.md`](docs/STATUS.md) first.** It is the single source of
truth for session state, the critical path, milestones, traps, and verify
commands. This file is the desktop architecture contract.

## What this is

Tool-Kit is a Tauri 2 + React/TypeScript **macOS-only** desktop app. Drop files
and folders, hit Run: the job comes from the drop, the output folder defaults
beside the input.

| Job | Service | In → Out |
|---|---|---|
| Convert | Datalab (`/api/v1/convert`, or a pinned pipeline) | PDF / DOCX / images / … → markdown |
| Transcribe | Rev.ai (async) | audio / video → text |

The bundle builds `app` + `dmg` only, and the three spawned sidecars plus the
loopback converter rule out the Mac App Store.

## Repository layout

Paths are repo-relative. Below, a bare `src/...` means
`apps/desktop/src/...`.

```text
apps/
  desktop/                  the .app: frontend + Tauri host
    src/                    app/ domains/ platform/ shell/ ui/
    src-tauri/              name kept: tauri.conf.json, .cargo/config.toml, and
                            dev-run.sh all resolve against this exact depth
      binaries/             staged sidecars, gitignored. `pnpm sidecars` fills it
      resources/            staged pdf-inspector bcmaps, gitignored, same script
  converter/                the HTTP service, container only
crates/
  worker-protocol/          wire contracts for every spawned worker
workers/
  vision/                   Swift, macOS 26+, cannot ship in the Linux image
contract/http/              OpenAPI spec, Spectral ruleset, Schemathesis config
deploy/docker/              Dockerfile, compose.yaml, secrets/
docs/
```

The image build context is the **repo root**, because the converter has a path
dependency on `crates/worker-protocol`. The root `.dockerignore` denies
everything and adds back only what the Dockerfile copies.

`src/ui` is not a package. An ESLint rule is the boundary, and `UI.md` names the
trigger for extracting it: a second client.

## Commands

Run from the repo root.

```bash
pnpm sidecars         # build + stage the three bundled binaries and the bcmaps. See below
pnpm tauri dev        # run the app with HMR (first run is slow: it compiles the Rust backend)
pnpm build            # frontend only: tsc + vite build
pnpm lint             # ESLint, type-aware (recommended + stylistic + react-hooks); kept clean
pnpm lint:fix

cargo check  --manifest-path apps/desktop/src-tauri/Cargo.toml
cargo clippy --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets -- -D warnings
cargo clippy --manifest-path apps/converter/Cargo.toml --all-targets -- -D warnings
```

**`pnpm sidecars` gates every cargo command**, not just the bundler. `pnpm
tauri` and `pnpm verify` run it, a bare `cargo` does not.

Both crates deny an extra clippy set in `Cargo.toml` `[lints.clippy]`
(todo/dbg/unwrap outside tests, unused async, non-exhaustive single-variant
matches). Knobs live in each crate’s `clippy.toml`. Do not enable
`clippy::pedantic` as a group.

### Suites written outside this repo

```bash
pnpm lint:api         # Spectral over contract/http/openapi.yaml (also in verify:backend)
pnpm verify:api-drift # schema.ts still matches the contract
pnpm verify:deps      # cargo-deny: RustSec advisories, licenses, sources
pnpm verify:contract  # Schemathesis against a live converter, needs uv
```

- **Do not re-add `prefixItems` to `inputFormats` or `engines`** in
  `contract/http/.spectral.yaml`. Both vary in length: 18 media types without
  Vision, 24 with it.
- **`schemathesis.toml` turns `positive_data_acceptance` off for
  `createConversion` alone**, where generated bytes carry no container signature
  and admission can never accept them.
- **`contract-fuzz.sh` runs the suite twice**, with a seeded conversion id and a
  UUID no conversion has: one pass hides a removed 404.
- **Both `deny.toml` files pin their platforms**, `src-tauri` to macOS, and
  every exception names its crate and reason.

### Release / signing / notarization (macOS)

```bash
# sign-only (fast; OK for local installs: locally-built apps aren't quarantined, so Gatekeeper allows them)
APPLE_SIGNING_IDENTITY="Developer ID Application: … (92MA44797J)" pnpm tauri build

# sign + notarize + staple (for the distributable DMG): additionally export APPLE_ID / APPLE_PASSWORD / APPLE_TEAM_ID
```

Artifacts: `apps/desktop/src-tauri/target/release/bundle/{macos/Tool-Kit.app,
dmg/*.dmg}`. The Developer ID cert needs Apple's **G2 intermediate**
(`certs.apple.com/devidg2.der`) in the keychain. Creds live in `.env.local`.

Two files are inputs to the signature: `entitlements.plist` (through
`bundle.macOS.entitlements`) and `embedded.provisionprofile` (through
`bundle.macOS.files`, copied into `Contents/` before signing). Get the profile
from the portal: an App ID for `dev.esfandiari.toolkit` with **Keychain
Sharing**, then Profiles → + → **Developer ID**. Commit it, it is public.

**Both keys are parked**, because `files` hard-errors without the profile. The
app signs without the entitlement, `secrets.rs` uses the legacy keychain, and
`verify-release.sh` fails its Keychain entitlement section by design. Restore
them when `apps/desktop/src-tauri/embedded.provisionprofile` exists:

```json
"macOS": {
  "minimumSystemVersion": "26.0",
  "entitlements": "entitlements.plist",
  "files": { "embedded.provisionprofile": "embedded.provisionprofile" }
}
```

The bundler signs each sidecar inner-out ahead of the `.app`, so
`build-sidecars.sh` does no signing and a re-sign breaks the nested seal.

**Restoring `entitlements` may hand entitlements.plist to all three sidecars.**
tauri-cli 2.11.4 appends `--entitlements` to every sign target. Run `codesign -d
--entitlements - --xml` against each helper before notarizing.

**Always check the bundle.** A build with no signing identity still succeeds:

```bash
apps/desktop/src-tauri/scripts/verify-release.sh              # after a sign-only build
apps/desktop/src-tauri/scripts/verify-release.sh --notarized  # adds stapler + Gatekeeper
```

It grades the designated requirement, `codesign --verify`, the Info.plist keys,
the font notices and stray gallery chunks.

**`pnpm tauri build` notarizes the `.app`, not the DMG.** A downloaded DMG reads
`rejected / source=Unnotarized Developer ID` while local installs work. Finish
it by hand:

```bash
xcrun notarytool submit <dmg> --apple-id … --password … --team-id … --wait
xcrun stapler staple <dmg>
```

Prove it the way a user gets it:

```bash
xattr -w com.apple.quarantine "0083;$(printf %x $(date +%s));Safari;" copy.dmg
spctl -a -t open --context context:primary-signature -vv copy.dmg
```

**A failed DMG step leaves a mounted image that breaks every later build**,
reported only as `failed to run bundle_dmg.sh`:

```bash
hdiutil detach /Volumes/dmg.* -force
rm -f apps/desktop/src-tauri/target/release/bundle/macos/rw.*.dmg
```

## Architecture

**Two apps, one repo.** `apps/desktop/` is the Tauri app (frontend at its root,
Rust crate in `src-tauri/`), `apps/converter/` is the conversion service,
`crates/worker-protocol/` is shared by both, `workers/vision/` is the macOS
Vision worker.

**One queue, pluggable providers**, because the services share one shape. The
UI reduces to inputs → output folder → `JobType` → Run.

**The backend does everything.** Network calls, secrets and file IO are in
Rust, and the webview holds no business logic.

**The converter ships inside the app**, and that layout is the contract:
`config.rs` and `backend_host.rs` find their children through
`current_exe().with_file_name(…)`.

```text
Tool-Kit.app/Contents/
  MacOS/       tool-kit  tool-kit-converter  tool-kit-pdf-worker  tool-kit-vision-worker
  Resources/   pdf-inspector/bcmaps/  (169 files)
```

**`backend_host::Deployment` is not a setting.** Sidecar spawns the converter on
`127.0.0.1:0`, reads the port off its listening line, mints a Keychain token and
stops it on exit. Manual needs `backend-override.json` beside `settings.json`,
which only `pnpm backend:docker` writes (`pnpm backend:sidecar`, `pnpm
backend:where`). Read origin and token through `backend_host::backend_origin`
and `backend_host::backend_token` alone, and never fall back to Sidecar on a
malformed override.

**The sidecar advertises 24 media types against Docker's 18**, because
`workers/vision/` is Swift and cannot ship in the Linux image, so images convert
locally in Sidecar mode only.

### Rust (`apps/desktop/src-tauri/src/`)

- **`providers.rs`**: the integration layer and main extension point, both
  services `submit → poll → fetch`. `send_retrying()` retries **only failures
  that prove the server never started work** (429/502/503/504/529, connect
  errors), only `SubmitError::Refused` may clear a billing claim, and
  `terminal_poll_error()` runs before any poll parse so a 401/404 fails the job
  rather than reading as pending.
  - **`Err` retries, `PollResult::Failed` kills the job**, and the result fetch
    treats 5xx and 429 as transient like the poll: that work is paid for.
- **`jobs.rs`**: `JobType` maps a job to its provider and extensions.
  `JobManager` is the queue, capped at **4 concurrent jobs**, emitting
  `job-updated` on every change, snapshotting Settings into `run_config` at run
  start, and writing with `create_new` so a colliding write fails the job. The
  tree pairs results through `result_extensions_for`, never the format setting.
  - **Every write-back to a job needs a `stale()` check.** `generation` is
    bumped by each run and by Stop, and a late write over a stopped row leaves a
    job no task will finish.
- **`history.rs`**: run history in SQLite (`history.db` beside `settings.json`),
  owning every statement against it, while `workspace.rs` owns
  `.toolkit/index.db`. **A storage error never fails a job.** A result is
  reusable only when source path, job and output format match, the output
  exists, and the mtime is unchanged.
  - **Never do the same work twice**, and **ask per file, never per route**. A
    result in the output folder means nothing happens, one elsewhere is copied,
    the rest go to the provider. Backend rows file under `backend:markdown` or
    `backend_fallback:{format}`, which never match.
- **`secrets.rs`**: keys in the **data protection keychain**, service
  `dev.esfandiari.toolkit`, group `92MA44797J.dev.esfandiari.toolkit`, accounts
  `datalab`/`revai`/`backend`. They never reach the webview or disk, and `set_key`
  alone drops the memo.
- **`settings.rs`**: non-secret config as JSON. **`#[serde(default)]` is
  load-bearing**: without it a new field fails every existing parse, `load()`
  answers with `unwrap_or_default()`, and the output folder and job reset
  silently. `save()` writes to a temp file and renames.
- **`tree.rs`**: one directory level from disk, owning every listing rule: the
  workspace-escape check, the dotfile and `project.json` filter, natural sort
  with folders interleaved, the source-to-result pairing (sibling stem plus
  `result_extensions_for`, `{stem} (n).{ext}`), the 500-entry cap, and whether a
  row opens. It holds no Tauri types, and `list_project_files` runs it off the
  AppKit main thread.
- **`backend_host.rs`**: owns the sidecar. It parses the port out of the
  service's `conversion service listening` line, mints the token through
  `secrets::set_key` **before** writing the 0600 token file, keeps the data root
  at `<app_data>/converter` so the replay ledger survives a launch, and stops
  the child by closing stdin **and** running `/bin/kill -TERM`.
- **`lib.rs`**: the Tauri command surface plus `setup()` (tray, ⌥⌘V shortcut,
  the **Settings…** item). `run_pipeline` expands the selection, clears the
  queue and spawns one job per match, refusing with `no_destination_message`
  when `output_dir_for` answers `None`. `import_into_project` stages an
  unimportable drop unchanged, so a file neither job accepts cannot vanish.
  - **`convert_one` is modelled on `retry_job`, never on `run_pipeline`.** It
    converts one file into the folder that file sits in, reads the generation
    instead of bumping it, appends one job rather than clearing the queue, and
    answers a refusal as a verdict (`kind`, `reason`, `message`).

### Adding a provider / job

Add a `JobType` variant and a `ProviderKind`, implement submit/poll in
`providers.rs`, and extend `JobType::accepts` plus the `Scan` struct in
`lib.rs`. The UI, queue, events and output handling are reused unchanged.

### Frontend (`apps/desktop/src/`)

`src/shell/App.tsx` owns all state and hands it to the views in
`src/domains/{run,library,onboarding,history,settings,thread}`. Its other
concerns are hooks beside it: `useToast`, `useDocuments` with `useDocumentSave`,
`useProjectTree`, `useHostWindow` and `useZoom`. Local state mirrors `Settings`
through `save_settings`, and the job list is authoritative from `job-updated`
events. Only `src/platform/host.ts` may import `@tauri-apps/*`,
and `src/app/commands.ts` is the typed IPC boundary. In `src/app/api/`, `pnpm
generate:api` writes `schema.ts` from the contract and `transport.ts` routes
every request through one `service_request` command, so the host attaches the
Keychain token.

- **Autodetect depends on `scan.convert`, `scan.transcribe` and
  `scan.suggestedOutput`**, never the whole `scan` object and never
  `settings.jobType`, either of which re-fires on an unrelated refresh and undoes
  a manual job click.
- **`runsFinished` is bumped once when a run ends.** A 200-file run emits
  hundreds of `job-updated` events, so reacting to those re-scans the disk that
  many times.
- **`starting` guards double-runs**: `running` derives from the job list, empty
  until the first event lands.
- **Progress reads `runJobs`, the queue minus `terminalAtStart`**, a baseline
  each door sets when it starts work. Retry and the badge read the whole queue.
- **Two panes, and the library is the fixed left one.** `view`
  (`"library" | "run" | "history"`) picks the right pane: the document pane,
  Run, or History. The split never collapses, and a tree door calls
  `setView("library")` first, or the file opens into a pane that is not on
  screen.
- **The tree keys everything on the workspace-relative path**, never an index,
  because a refresh reorders rows. Freshness is `runsFinished` plus a debounced
  focus reconcile over `changed_project_dirs`, with no watcher and no reaction
  to `job-updated`. Only a folder the host reports **gone** (a `ListError`) may
  drop a path from `settings.expandedPaths`.
- **A finished run expands the folders it wrote into**, through `resultDirs`.
  Reading `activeProjectPath` opens the wrong project, since a run writes beside
  each source.
- **The tree asks the host for a verdict, it never plans a conversion.**
  `convert_one(rel)` answers `queued`, `copied`, or `blocked` with a reason, and
  `blocked` stages the file in Run except `not_convertible`, which toasts alone
  because no hint can resolve it.
- **Settings is a sheet, not a view**, so opening it cannot evict the Run column
  mid-run. Escape runs one ordered handler: sheet, inspector card, document.
- **Zoom is the whole app**, stepped along the `ZOOM` ladder by index, not by
  adding to the factor, because `1 + 0.1 - 0.1` is not 1 in floating point.
- **Inputs auto-clear only when `run()` started the run and something
  succeeded.** Every staging door goes through `addPaths`, which stands the
  auto-clear down.

### Design system (`apps/desktop/src/ui`, docs in its `UI.md`)

**Read `src/ui/UI.md` before touching any UI.** Its four rules are the reason to
reject a change:

1. **Colour is signal, never decoration.** `--status-warning` = live,
   `--status-success` = passed, `--status-danger` = failed, `--status-info` =
   note. The control you press is ink on bone. Icons are never coloured.
2. **Values light up, they don't appear.** Counts and timers hold their slot as
   ghost glyphs so the window never reflows while jobs finish.
3. **macOS first.** Opaque surfaces that follow the system appearance through
   `light-dark()`, `body.inactive` states, one 1px focus ring, tabular
   numerals, native `<select>` and checkboxes.
4. **Whitespace is a grammar.** `--s1`..`--s8` run from atoms of one object to
   the window edge, and the gap is inversely proportional to the relationship.

Three families: **TRJN DaVinci** display, **DM Sans** prose, **Red Hat Display**
500 for every label, tab and button (uppercase, `0.22em` tracked). All
self-hosted: two OFL families plus DaVinci, licensed.

- **ESLint enforces the `@ui` boundary**: nothing under `src/ui` imports from
  `@/app`, `@/domains`, `@/platform`, or `@tauri-apps/*`.
- **A primitive with no specimen in `Gallery.tsx` does not exist.** Add it in
  the same commit, reviewed at `http://localhost:1420/?gallery`.
- **Cascade layers, not import order.** `base.css` and `App.css` both declare
  `@layer ui, app;`, each `ui/primitives/*.css` wraps in `@layer ui` and
  `App.css` in `@layer app`, so an app override wins at any import order.
- **`src/shell/App.css` is app composites only** and carries no `:root` block. A
  new custom property belongs in `tokens.css` or on its own element.

## Gotchas

- **An unsigned release build cannot ship and cannot reach the keychain.** Its
  designated requirement is `cdhash H"…"`, so Gatekeeper rejects it elsewhere
  and the restricted `keychain-access-groups` entitlement is dropped. A
  Developer ID build gets `identifier "dev.esfandiari.toolkit" … subject.OU =
  "92MA44797J"`, stable across versions.
- **Only the data protection keychain has no dialogs.** The legacy store binds
  each item's ACL to the designated requirement, so a signature change voids
  every "Always Allow". A bare `cargo run` Mach-O carries no profile, gets
  `errSecMissingEntitlement` (-34018), and keeps its own keys. Exercise the real
  path with `pnpm tauri build --debug`.
- **The provisioning profile is pinned to the signing certificate**, which
  expires **2031-06-18**. Rotate the cert and you must regenerate the profile,
  or the app will not launch.
- **`pnpm lint` runs `scripts/lint-tokens.sh`.** A literal colour, radius,
  shadow, blur or font family under `src/`, outside `ui/tokens.css` and
  `ui/fonts.css`, fails it.
- **`pnpm sidecars` gates `cargo`, not just the bundler.** A missing staged
  binary fails `cargo check`/`clippy`/`test` and `pnpm tauri dev` with
  `ResourcePathNotFound`, on every fresh clone and `git clean`.
- **`Contents/MacOS` is sealed as nested code, so only executables go there.**
  The bcmaps are a `resource`: a data file breaks the seal on the user's machine
  while every build-machine check passes. `verify-release.sh` sweeps it.
- **`TOOLKIT_CONVERTER_PDF_BCMAPS_DIR` fails silently when unset.**
  `pdf-inspector` falls back to a path that exists only on the build machine, so
  CJK PDFs lose their ToUnicode mapping. A missing bcmaps resource is fatal on
  purpose.
- **Set `RUST_LOG` for the child, never inherit it.** The supervisor learns the
  sidecar's port from one log line, and a quieter inherited filter suppresses
  it: the app hangs at Starting.
- **`RunEvent::Exit`, not `ExitRequested`**, which never fires on ⌘Q because the
  window hides. A long blocking wait there stalls AppKit termination, so the
  shutdown grace is 5s and the Exit path caps at 7.
- **A converter that reads stdin must not read it on tokio's blocking pool.**
  Dropping the runtime waits for started blocking tasks, so SIGTERM goes inert
  and the process hangs after `main` returns. Use a detached `std::thread`.
- **Core Tauri commands need capability entries, custom ones do not**, and a
  missing one fails silently at runtime. `core:window:default` excludes
  `hide`/`destroy`, and sizing, zoom and the hidden launch added
  `set-max-size`, `set-resizable`, `current-monitor`,
  `webview:set-webview-zoom`, `show` and `set-position`. **Never add a
  `permissions/` directory**: it flips `has_app_manifest()` to true, and every
  custom command without an ACL entry is then rejected.
- **A window focus event never reaches a `getCurrentWebview()` listener.** It
  goes only to Window targets, so the listener subscribes cleanly and never
  fires. Use `getCurrentWindow().onFocusChanged`.
- **A fixed toast is invisible under a modal `<dialog>`**, which renders in the
  top layer, so `Sheet` takes an `overlay` slot. A modal also makes the document
  inert, so the sheet carries its own `data-tauri-drag-region` strip.
- **An app-menu item id must not collide with the tray's** `"show"` or
  `"quit"`, which a global `on_menu_event` closure matches. Splice with
  `Submenu::insert`, never `set_menu`, which drops Edit, View, Window and Help.
- **Window geometry lives in `src/shell/geometry.ts` and nowhere else.**
  `INITIAL` has no reader, because JSON cannot import: it records what
  `tauri.conf.json` opens at. `WORKSPACE.minWidth` derives from
  `SPLIT.minStart`, so `SPLIT.start`% of the minimum window must clear the
  floor. Change one, redo the other.
- **The window opens hidden, and the frontend sizes, places and shows it.**
  macOS clamps `setSize` to the bounds in force at that instant, so move the
  bounds first: `setResizable(true)` → `setMinSize` → `setMaxSize` → `setSize`.
  **Do not reach for the host's own `center()`**: tao applies `setSize`
  asynchronously and it centres the pre-grow frame. `setup()` shows the window
  after 3s regardless.
- **⌘+/- is page zoom and does not move the traffic lights**, which macOS draws
  in logical pixels. Chrome measured against one divides by the factor:
  `calc(64px / var(--zoom, 1))`, published on `:root` by `useZoom`.
- **`react-resizable-panels` reads `defaultLayout` by panel id but re-keys
  `setLayout` by panel order**, so a Rust `BTreeMap` arriving as `{end, start}`
  opens the split inverted, and only `paneLayout` may construct one.
  `defaultLayout` is also validated against the panels present at mount, and the
  group registers its second panel a render later, so `SplitPane` re-applies
  the saved layout after mount and retries.
- **`icons/mark.png` is missing and has never been in git**, so
  `icons/make-icons.py` cannot regenerate the `.icns` ladder. Redraw it, never
  upscale a shipped icon. `tray.png` and `tray@2x.png` take their alpha from the
  mark, never from `icon.png`.
- **The global shortcut is ⌥⌘V**, not ⌘⇧V: that one is macOS "Paste and Match
  Style", and registering it hijacks that chord system-wide.
- **Datalab pipeline mode**: a `pl_…` id in Settings switches Convert to
  `/api/v1/pipelines/{id}/run`, then polls and fetches the last step.
- **Pinned toolchain.** TypeScript stays on 6.x (7.0 has no compiler API and
  `typescript-eslint` crashes). `tsconfig.json` must not set `baseUrl`.
  `security-framework` needs the non-default `OSX_10_15` feature, which gates
  `use_protected_keychain()`. pnpm 11 gates build scripts, so esbuild is
  approved in `pnpm-workspace.yaml`.
- **One tree, two crates.** Do not create a root Cargo workspace: `src-tauri`
  and `backend` keep separate lockfiles. Never `git add -A`, because desktop and
  backend work share one dirty tree.
