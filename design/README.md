# Design sources

Reference for the port in `docs/DESIGN_PORT.md`. Nothing here is built or
imported by the app.

  claude.ai/design project `30b59ea7-dc23-4a0c-aa16-e279c2409106`, exported
  2026-09-12. Website kit, specimens, photos, and generator files were left out.
